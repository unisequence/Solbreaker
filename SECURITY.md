# Security reports

Report vulnerabilities privately through
[GitHub's security advisory form](https://github.com/unisequence/Solbreaker/security/advisories/new).
Do not publish working exploits, credentials or private account data in an issue.

Include the affected release or commit, the configuration needed to reproduce
the problem, its impact and a minimal reproduction. Redact secrets from logs
and use a disposable account for examples.

This is an alpha project. Fixes target the current release and main branch;
older alpha versions do not have a separate maintenance branch. There is no
guaranteed response time.
