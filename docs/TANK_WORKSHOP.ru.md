# Solbreaker Workshop

[English guide](TANK_WORKSHOP.md)

Workshop собирает отдельный танк для Solbreaker. Проект хранится в `tank.toml` рядом с моделями и текстурами. Из одного проекта можно собрать пакет для сервера и всех участников боя.

## Собрать танк

Скачай архив Workshop с [GitHub Releases](https://github.com/unisequence/Solbreaker/releases/tag/workshop-v0.1.0-alpha.1)
и распакуй его в отдельную папку. Для редактора нужен Python 3.11+ и собственная копия игры
сборки `11.21.0.1235_7376187`. Для импорта GLB нужен Blender в `PATH`.

В папке `Solbreaker` установи зависимости и открой редактор.

```sh
python3 -m venv .venv
./.venv/bin/python tools/install_dependencies.py --profile gui
./.venv/bin/python -m solbreaker tank-workshop --language ru
```

На Windows для запуска редактора используй PowerShell.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe tools\install_dependencies.py --profile gui
.\.venv\Scripts\python.exe -m solbreaker tank-workshop --language ru
```

Без `--language` редактор берёт язык из настроек лаунчера. Допустимые значения — `ru` и `en`.

На стартовом экране выбери готовый танк из локальной игры или перетащи свой GLB. Для проекта на готовой машине Workshop сохраняет ссылку на её модель.

### Смешать детали разных танков

На вкладке **Сборка** кликни по детали на модели или её слоту справа. Найди донора по названию или нации и выбери его карточку. **Отменить замену** возвращает предыдущую сборку. Чтобы вернуть деталь из исходного танка, очисти поиск и выбери **Из исходной модели**.

Workshop подгоняет башню по погону, а орудие по маске, когда геометрия позволяет измерить зазор. После ручного сдвига он подсвечивает место заметного зазора или пересечения. **Подогнать** возвращает деталь в допуск, если поправка укладывается в рабочий диапазон. Это проверка в текущем положении орудия и башни.

Ручки на модели сдвигают выбранную деталь вверх или вдоль корпуса. Точные координаты есть на вкладке **Точки**, а размеры ходовой — на вкладке **Траки**. Корпус, башня и орудие используют модель и карту брони выбранного донора. Боеприпасы и поведение орудия задаются базовым танком и параметрами проекта.

Для пересылки используй архив Workshop. Ссылки на выбранных доноров сохраняются в проекте, а модели читаются из закреплённой локальной сборки при установке.

### Проверить в игре

На Linux открой `./launch-gui.sh` из папки Workshop и подготовь отдельный локальный
сервер и клиент с Proton. Для подготовки сервера нужны Rust/Cargo 1.85+ и инструменты
сборки из [руководства по установке](INSTALL.ru.md#установка-на-linux).

Закрой игру и останови сервер, затем нажми **Проверить в игре**. Workshop
установит текущий танк в подготовленный сервер и клиент и запустит Полигон. Если
открылась форма входа, войди в Solbreaker. При сбое запуска смотри
`private/launcher-client.log` в папке подготовленного клиента и `server.log` в папке сервера.

### Импортировать свою модель

1. Нажми «Новый» и сохрани `tank.toml` в отдельной папке. Во вкладке «Ресурсы» открой GLB или пару SC2/SCG. Для SC2/SCG визуальная модель и коллизии импортируются отдельно. Текстуры назначаются по именам слотов модели.
2. Проверь корпус, башню, орудие и дуло на вкладке «Точки». Можно указать координаты вручную или поставить точку кликом по модели. Включи показ коллизий, чтобы проверить их положение. X смотрит вправо, Y вверх, Z вперёд. Координаты в метрах относительно начала модели.
3. Укажи ID пакета, свободный числовой ID машины для её нации, название, уровень, HP, скорость, мощность, перезарядку и урон основного снаряда. Для материала брони № 1 можно задать толщину по деталям. Остальные параметры экипажа, орудия и боекомплекта берутся у базовой машины. Для первого проекта используй `ussr/R43_T-70_57`.
4. Нажми «Экспорт пакета» и выбери имя для `*.tank.zip`. Участникам нужен один и тот же архив.

## Подготовить GLB в Blender

Создай отдельные объекты или родительские узлы `hull`, `turret_01` и `gun_01`. Их начала координат задают исходные точки крепления. Поставь Empty `HP_gunFire_01` на дульном срезе. GLB должен включать отдельные низкополигональные объекты `collision_hull` и `collision_turret_01`. Для ствола можно добавить `collision_gun_01`.

Ориентация исходной сцены в Blender — Z вверх и +Y вперёд. Экспортируй в glTF Binary с обычным преобразованием осей Blender. Для окраски импортируется Base Color из Principled BSDF. Можно назначить PNG, JPEG или DDS после импорта. Для собственной статической ходовой добавь `chassis_track_L` и `chassis_track_R`. Коллизии GLB используют один материал брони на деталь.

## Примерить ходовую

Для подгонки ходовой открой вкладку **Траки**. Кнопка **Подогнать под модель** вписывает ходовую в габариты исходной пары гусениц. Размеры и точные смещения можно ввести справа. Галочка **Показать ход траков** рисует движущиеся точки вдоль контура ленты.

В пакете сохраняются имя донора и размеры. При установке Solbreaker собирает ходовую из локальных ресурсов закреплённой сборки. Игровые текстуры донора читаются клиентом из его подготовленной копии игры.

В разработке Workshop использовался OpenAI Codex. Примерка деталей вдохновлена конструктором [BlitzInfo](https://blitzinfo.app/wg/11.21.0_1/build/). Код распространяется по [лицензии Solbreaker](../LICENSE).

## Установить пакет

Закрой клиент и останови сервер перед установкой. В Workshop нажми «Установить…» и выбери клиент или сервер. Установи один и тот же архив в каталог состояния сервера и в подготовленный клиент каждого участника. Те же действия доступны из консоли.

```sh
python -m solbreaker install-tank my-tank.tank.zip --state /path/to/state
python -m solbreaker install-tank my-tank.tank.zip --client /path/to/prepared-client
```

Запусти сервер и зайди в игру. На сервере с выдачей всей техники машина появится в ангаре среди танков выбранной нации и уровня. При повторной установке обновления используй тот же ID пакета и числовой ID. Установщик проверяет занятые ID, наличие модели, боекомплект и коллизии перед активацией.

Серверная установка использует Linux. Полный цикл проверяется на клиентах Proton с закреплённой сборкой 11.21.0.1235_7376187. Скопированный клиент Windows требует отдельной проверки. Пакет устанавливается вручную на каждого участника. В архив входят проект и его ресурсы. Каталоги и данные базовой машины создаются при установке из локальной копии игры.
